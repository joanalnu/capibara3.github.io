We've rebuilt the CAPIBARA website to be simpler and easier to maintain. Documentation now lives on its own site,
while this one focuses on what matters most: who we are, what we're building, and what's new.

## What's here

- **Missions:** CRD and GAMMA each have their own page.
- **News & publications:** posts like this one, written in plain Markdown.
- **Join us:** everyone is welcome, no experience required.

## Adding a post

Create a new `.md` file in `src/content/blog/` with this frontmatter and write below it:

```md
---
title: "Your title"
description: "One-sentence summary."
date: 2026-11-01
tags: [news]
---
```

Set `draft: true` to keep a post hidden until it's ready.
